# CBOS Demo Recordings

This folder contains demo walkthrough assets for presenting CBOS to a chiropractic practice owner, office manager, or front desk lead.

## Files

- `cbos_walkthrough_demo_narrated.mp4` - narrated walkthrough using fake local demo data.
- `cbos_walkthrough_presenter_script.md` - live presenter script to use during an in-person or Zoom demo.
- `cbos_walkthrough_narration.txt` - narration text used to generate the recorded walkthrough.

## Positioning

Present CBOS as a lightweight follow-up and reactivation layer beside the practice's existing tools. Do not position it as an EHR, billing system, insurance system, or scheduling replacement.

## Demo Notes

- Use fake or sanitized data only.
- Start with the dashboard and follow-up queue.
- Keep the conversation focused on missed inquiries, follow-up consistency, reactivations, and weekly owner visibility.
- End by asking whether the workflow would make today's follow-up work easier to see.
